Naravel Events Sample

Dispatches an OrderPlaced event through Naravel.Events and shows which listeners ran.

  • DI listeners run synchronously, in registration order (fraud screen, then read model)
  • A Listen callback registered for the request runs after the DI listeners
  • The receipt listener is queued: dispatch only enqueues it and the worker runs it later
  • An order above 10,000 makes the fraud screen call context.Stop(), so nothing after it runs

Place an order to see the trace.

The queued receipt appears after the worker processes it (about a second). The queue worker uses the connection configured in NaravelQueue:SampleConnection, and the adapter dispatches on NaravelQueue:Default; keep them equal.
