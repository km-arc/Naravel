Naravel Database Sample

A people table in an in-memory SQLite database, read through the Naravel query builder. Each button builds a different query; the answer shows the SQL (with @p markers), the bound values and the rows.

  • Conditions are added only when a parameter is present, and every value is a bound parameter
  • A hostile value (x' or '1'='1) is just text to match, never SQL
  • A column name from the caller (orderBy) is validated: a bad one is rejected before any SQL exists
  • born is filtered with WhereYear, which becomes strftime on SQLite and extract, year() or datepart elsewhere
