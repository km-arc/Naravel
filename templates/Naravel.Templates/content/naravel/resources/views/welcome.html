1. Add a route routes/WebRoutes.cs, inside app.MapNaravel(routes => ...)

A group takes a prefix, a name prefix and middleware, as in Laravel. throttle is built in: 60 requests a minute for each caller, then 429.

routes.Prefix("api").Name("api.").Middleware("throttle:60,1").Group(api =>
{
    api.Get("posts/{id}", (int id) => $"post {id}")
       .Where("id", "[0-9]+")
       .Name("posts.show");
});

routes.Prefix("admin").Middleware("role:admin").Group(admin =>
{
    admin.Get("stats", () => "only for admins").Name("admin.stats");
});

2. Write a middleware app/Http/Middleware/RequireRole.cs

A middleware that does not call next ends the request. role:admin passes admin in as an argument. The header check stands in for your own rule.

using Naravel.Routing;

namespace AppRootNamespace.App.Http.Middleware;

public sealed class RequireRole : IRouteMiddleware
{
    public async Task InvokeAsync(HttpContext context, RequestDelegate next,
        MiddlewareArguments arguments)
    {
        var role = arguments.At(0) ?? "user";   // "role:admin" gives "admin"
        if (context.Request.Headers["X-Role"] != role)
        {
            context.Response.StatusCode = StatusCodes.Status403Forbidden;
            return;                             // stop here, next is not called
        }
        await next(context);
    }
}

Register it under the name role in Program.cs, where AddNaravelRouting() is called now (add using AppRootNamespace.App.Http.Middleware; at the top):

builder.Services.AddNaravelRouting(o => o.Middleware.Alias<RequireRole>("role"));
