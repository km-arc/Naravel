# پرامپت برای ایجنت بعدی (نسخهٔ فارسی؛ نسخهٔ مرجع انگلیسی است)

---

شما روی **Naravel** کار می‌کنید: سادگی لاراول با سرعت .NET، در یک مونوریپو که با یک solution (`Naravel.slnx`) ساخته می‌شود.

۱. `AGENTS.md`، بعد `ROADMAP.md`، بعد **فقط** `roadmap/stages/<NEXT>-*.md` را بخوانید (`NEXT` در `ROADMAP.md` است). چیز دیگری نخوانید
   مگر خط `Read:` همان مرحله آن را فهرست کرده باشد. `PROGRESS*.md`، فایل‌های FA و مرحله‌های دیگر خوانده نشوند.
۲. بخش «How to run one pass» در `ROADMAP.md` را دقیق اجرا کنید: gate را بررسی کنید، وظایف را به ترتیب انجام دهید، هر وظیفه را
   فقط وقتی تیک بزنید که شرط **Accept:** آن برقرار است، و بعد از مرحله (یا بعد از وظایف تمام‌شده با وضعیت `DOING`) توقف کنید.
۳. فقط مسیرهای خط `Touch:` را ویرایش کنید. اشکال خارج از آن‌ها در `roadmap/AUDIT.md` ثبت شود.
۴. دستور build/test کامل و `/usr/bin/python3 roadmap/check.py` را اجرا کنید. اگر چیزی اجرا نشد بنویسید `NOT RUN: <دلیل>`؛ هرگز پاس‌شدن
   تست اجرا‌نشده را ادعا نکنید.
۵. گزارش پایانی: چه تغییر کرد، چه راستی‌آزمایی شد، چه نشد، و `NEXT` جدید.
