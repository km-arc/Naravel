# Documentation

This index is the entry point for Naravel's maintained English documentation. Documentation is kept in one authoritative language so API descriptions, examples, and package guidance can be reviewed against the implementation without translation drift.

Accepted and declined design decisions are recorded in [docs/pdr/en](pdr/en/). PDRs explain the Laravel concept, the native .NET alternative, the value added, the decision, and rejected alternatives.
