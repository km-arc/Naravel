# R24 — Query builder: Unions, subqueries, CTEs, locks, raw and debugging

Parity section: `R24` in [../PARITY-MATRIX.md](../PARITY-MATRIX.md).
Gate: PDR-022 (EN+FA) approved first.
Read: PDR-022, the coverage ledger rows for R24, the `Raw` safety rules from R19.
Touch: `src/Naravel.Database/**`, `tests/Naravel.Database*.Tests/**`, docs EN/FA.
Out of scope: Transactions (R25).
Decisions: Every `*Raw` method takes bindings and is the only way SQL text enters a query; a test greps the public API for string parameters that are interpreted as SQL outside `Raw`.

## Tasks
- [x] **R24.T01 — Unions:** `Union`, `UnionAll` with ordering and limit on the union. **Accept:** SQL tests per dialect (SQL Server and SQLite parenthesis rules). Added with compile tests on four grammars, SQLite execution tests and contract scenarios, EN/FA docs; build and tests NOT RUN locally (no .NET SDK); CI is the check. Decisions: ordering and limit set after the first `Union` apply to the whole union, those set before stay with the first select; a term or union with ordering or a limit becomes a derived table on every dialect; added queries are copied; a union query is read-only.
- [x] **R24.T02 — Subqueries:** `SelectSub`, `FromSub`, `JoinSub`, `LeftJoinSub`, `RightJoinSub`, `JoinLateral`, `LeftJoinLateral`, subquery where forms. **Accept:** binding-order tests; lateral on SQLite throws `NotSupportedException`; SQL Server uses `CROSS/OUTER APPLY`. Added with compile tests on four grammars, SQLite execution tests and contract scenarios, EN/FA docs; build and tests NOT RUN locally (no .NET SDK); CI is the check. Decisions: the methods take a `Query` (no closure forms); subqueries are copied when added; a query with a subquery source or join is read-only; the subquery where forms (`WhereIn`, `WhereExists`, `WhereSubquery`) were already done in R21.
- [x] **R24.T03 — CTEs:** `WithExpression`, recursive CTE. **Accept:** SQL tests per dialect (`WITH RECURSIVE` vs SQL Server `WITH`); a tree-walk execution test. Added with compile tests on four grammars, a SQLite tree-walk test and contract scenarios, EN/FA docs; build and tests NOT RUN locally (no .NET SDK); CI is the check. Decisions: four methods (`WithExpression` and `WithRecursiveExpression`, each with and without a column list); the query is copied when added; count and exists hoist `with` out of their derived table; writes and insert sources refuse expressions; `option (maxrecursion)` is not written.
- [x] **R24.T04 — Raw expressions:** `Raw`, `SelectRaw`, `WhereRaw`, `OrWhereRaw`, `HavingRaw`, `OrHavingRaw`, `OrderByRaw`, `GroupByRaw`, `FromRaw`. **Accept:** binding tests and injection tests. Added with compile tests on four grammars, injection tests (values, identifiers, operators, directions), the reflection test of the stage decision, SQLite execution tests and a contract scenario, EN/FA docs; build and tests NOT RUN locally (no .NET SDK); CI is the check. Decisions: `Raw` is a value type accepted by every value position (it expands in the compile context), not a separate method family; `SelectRaw`, `WhereRaw`, `OrWhereRaw` and `OrderByRaw` already existed from R19 and R21.
- [ ] **R24.T05 — Locks:** `SharedLock`, `LockForUpdate`. **Accept:** SQL per dialect (`FOR SHARE`, `FOR UPDATE`, `WITH (HOLDLOCK)`/`UPDLOCK`); SQLite throws `NotSupportedException`.
- [ ] **R24.T06 — Debugging:** `ToSql`, `ToRawSql` finalized and documented; `dump`/`dd` not ported. **Accept:** `ToRawSql` escapes values per dialect and is documented as for logs only, never for execution.
- [ ] **R24.T07 — Validate:** Docs EN/FA, parity, changelog, full verification. **Accept:** DoD 5-7.
