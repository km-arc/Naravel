# R19 — Query builder: Database core, SQLite and basic queries

Parity section: `R19` in [../PARITY-MATRIX.md](../PARITY-MATRIX.md).
Gate: PDR-022 (EN+FA) approved first (R19.T01).
Read: `docs/pdr/en/PDR-022-database-query-builder.md`, `src/Naravel.Foundation/Manager.cs`, `src/Naravel.Cache/CacheManager.cs` (a Manager-based module), `roadmap/QUERY-BUILDER-COVERAGE.md`.
Touch: new `src/Naravel.Database/**`, `src/Naravel.Database.Sqlite/**`, `tests/Naravel.Database.Tests/**`, `Naravel.slnx`, `Directory.Packages.props` (Dapper, Microsoft.Data.Sqlite only), docs EN/FA, PDR-022.
Out of scope: Drivers other than SQLite (R20); joins, grouping and the extended where family (R21); writes (R23).
Decisions: PDR-022 amendment A1-A4 applies: the connection/transaction seam (`IConnectionScope`, `IConnectionLease`), Dapper limits, the frozen identifier/operator grammar and `MaxParameters` are built and proven here. Grammars for all four dialects are written here for the methods in this stage, so dialect SQL is unit-tested without a database; only SQLite is executed. Safety rules (parameters only, validated and quoted identifiers, explicit `Raw`) are fixed here and never relaxed later.
